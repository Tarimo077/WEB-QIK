Architecture & Performance

Platform Migration Overview

Transition from WordPress / WooCommerce to Custom Django

Executive Summary

Migrating from WordPress to a tailored Django architecture provides a lightweight, highly maintainable, and secure foundation designed specifically for agricultural e-commerce in Kenya. By shedding plugin bloat, database overhead, and rigid theme layers, this implementation directly improves page speed, mobile usability, SEO discoverability, and administrative agility.

1. Performance & Page Speed

Dimension Legacy WordPress / WooCommerce New Custom Django Platform
Asset Delivery 30+ separate CSS/JS plugin bundles Single compiled Tailwind CSS bundle with WhiteNoise compression
Server Latency (TTFB) 800ms – 2500ms (PHP hook chains) 50ms – 200ms lightweight Python WSGI/ASGI responses
Client Overhead Heavy render-blocking scripts & jQuery Zero third-party runtime frameworks; native Vanilla JS
Core Web Vitals High Cumulative Layout Shift (CLS) Zero CLS with pre-sized containers and optimized local assets
Catalog Pagination Full page reloads losing active filters User-selectable (10, 20, 50) with query state preservation

2. Superadmin Live Editor & Real-Time Preview Portal

Unlike standard WordPress customizer tools or rigid table editors, the platform includes a dedicated Superadmin Live Editor & Preview Portal (/superadmin/live-editor/):

  • Universal DB Entity Editing: Superadmins can modify Products, Categories, Promotions, and Site Settings (announcements, hero banners, phone numbers, WhatsApp lines, addresses, operating hours) directly from one screen.
  • Dual-Mode Image Management: Direct file upload (drag-and-drop or file picker) into Django media storage or external image URLs, with instant client-side object URL live previews.
  • Instant In-Memory Live Preview: Renders live component previews (Grid Cards, List Cards, Product Detail Views, Category Headers, and Banner Contexts) in real time as the admin types, before writing to the database.
  • Multi-Device Viewport Switching: One-click preview testing across Desktop (100%), Tablet (768px), and Mobile (375px) viewports to verify layout responsiveness before publishing.
  • Storefront Quick Launcher: Authenticated superusers have a floating ⚡ Live Editor button on the storefront for immediate access.
  • Zero-Downtime Content Updates: Dynamic SiteSetting models and context processors eliminate code edits and deployments for updating phone numbers, WhatsApp lines, or hero promotions.

3. Mobile-First Storefront, Filtering & Sorting Engine

  • Multi-Metric Sorting: Instant ordering by Price (Low to High / High to Low), Alphabetical (A to Z / Z to A), Newest Arrivals, and Featured / Best Match.
  • Multi-Faceted Filtering Suite: Filter simultaneously by real-time Category counts, custom Min/Max Price bounds & presets, Stock Availability (In Stock Only / Pre-Order), and special deals (On Sale / Featured).
  • Active Filter Chips: Removable filter pill chips allow buyers to dismiss individual filter criteria with a single tap.
  • Mobile Filter Slide-Out Drawer: Touch-optimized slide-over drawer enabling complete sorting and filtering on smartphones without page disorientations.
  • Mobile App Experience: Integrated slide-out navigation drawer and a fixed bottom navigation bar with real-time cart and wishlist counter badges.
  • Universal Grid & List View Toggle: Available across all product listings (Shop, Daily Deals, and Wishlist) allowing buyers to switch between visual gallery cards and information-dense list cards.
  • User-Selectable Pagination: Buyers can choose between 10, 20, and 50 products per page with touch-friendly navigation controls, active page pill indicators, and query state preservation.
  • Automatic Discount Percentage Badges: Dynamically computes and displays -X% badges on products with active promotions or reduced comparison prices.
  • Clean Brand Logo: Pure alpha-transparent logo assets integrated seamlessly without background box artifacts.

4. Security & Maintenance Overhead

  • No Third-Party Plugin Risk: Replaced bloated third-party plugins with clean native Django modules for sessions, sitemaps, messaging, and search.
  • Zero Breaking Updates: Eliminates site crashes caused by automated plugin or theme updates clashing with PHP runtimes.
  • Built-in Security Defaults: Enforced native CSRF verification, parameterized ORM SQL injection protection, and XSS auto-escaping.

5. Custom E-Commerce & Market Localization

  • Direct WhatsApp Order Routing: Pre-formats items, quantities, and totals directly to WhatsApp instead of forcing multi-step checkouts.
  • Instant Search & Live Toasts: Client-side debounced search suggestions and real-time top-right notifications without full page refreshes.
  • Clean Currency Formatting: Native Kenyan Shilling (KSh) formatting across the entire catalog.

6. Architectural Scalability & Infrastructure Cost

  • Stateless Client Sessions: Signed cookie sessions eliminate database writes during cart browsing, reducing database load.
  • Lower Compute Overhead: Accommodates higher concurrent traffic on entry-level hosting or serverless tiers.
  • Clean Relational Data: Eliminates slow wp_postmeta table queries in favor of direct relational tables.
